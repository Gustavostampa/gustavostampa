<product_requirements>
Stampa Confere is a WMS-like application for goods conferencing, designed to be offline-first and PWA-compatible for Android scanners. It features distinct Gestor (Manager) and Conferente (Checker) interfaces.

**Gestor Interface:** Handles product/load imports (Caixaria, Multi-pedidos) via Excel, user management (CRUD), real-time monitoring, historical data, and Excel exports. Includes Product CRUD with unique EANs and 'ativo' status.
**Conferente Interface:** Manages loads (start, pause, finalize), EAN scanning with real-time feedback (OK, difference, out-of-list), reconferencing, and load synchronization.
**Core Features:** Login with profile-based redirection, persistent sessions, isolated local cache, one active/paused load per user.
**Implemented Features (prior to current debugging):** Finalization flow (modal summary, reconferencing), max one paused load per user, Sobra (out-of-list EANs) recording, Multi-pedidos recipient selection modal, and confirmation before starting a conference.
**Recent Enhancements:**
1.  **Finalization Flow:** Ability to mark loads as finalizada, move them from Em andamento to a Finalizados tab (Gestor), with a backend endpoint for listing.
2.  **Multiple EANs per Product:** Proper handling of different EANs for the same product, without quantity multiplication, where each EAN (UN, CX, EXB) is treated as a distinct item.
3.  **Multi-pedidos Filtering:** Filter load items by recipient, finalize individual recipients, and display progress within a multi-pedido session.
</product_requirements>
