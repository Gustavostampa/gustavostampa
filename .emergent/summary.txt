<product_requirements>
<product_requirements>
The goal is Stampa Confere, a WMS-like application for goods conferencing with two independent interfaces: Gestor (Manager) and Conferente (Checker). It must be offline-first, PWA-compatible, and support simultaneous use on Android keyboard-wedge scanners.

**Gestor Interface**: Import products, loads (Caixaria, Multi-pedidos) via Excel with preview and validation, manage users (CRUD), real-time monitoring, historical data, and Excel export. Also includes Product CRUD screen (list, search, create, edit, delete, unique EAN, 'ativo' status, block deletion if in active loads).
**Conferente Interface**: Select date, choose load type (Caixaria/Multi-pedidos), manage load sessions (start, pause, finalize), perform EAN validation via scanner (Enter/Tab event) with real-time status updates (green/red/dark red for OK, difference, out-of-list), and reconferencing items with differences. Must include load synchronization (automatic/manual/interval).
**Core Features**: Login with profile-based redirection, persistent sessions, data synchronization, multi-user concurrency (isolated local cache, single active/paused load per user), local data management (clear cache, full reset).
**New Features (in-progress/implemented)**:
- **Finalization Flow**: Modal summary, reconferencing options (recount/manual adjust), offline finalization, sync triggers.
- **Sessões**: Max 1 paused load per user, blocking if attempting to pause more.
- **Sobra**: Record and highlight out-of-list EANs in a dedicated tab, include in summary/export.
- **Multi-pedidos**: Mandatory Recipient filter before listing products, display active recipient, new session on recipient change.
- **Confirmação ao Iniciar Conferência**: Modal with load details and paused load warning.
</product_requirements>
